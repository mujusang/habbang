# 가온자리 표준 합방기

한국중경의학회 표준 버전 처방 조제 시스템 (단일 HTML, 외부 의존 없음).

- 사용 주소: https://mujusang.github.io/habbang/
- 열람: 비밀번호 잠금 문서입니다. 비밀번호는 가온자리한의원 원장님께 확인하세요.
- 파일: `index.html` — 문서 전체가 AES-GCM(PBKDF2-SHA256)으로 암호화되어 있고, 화면에서 비밀번호를 입력하면 브라우저 안에서 복호화됩니다. 평문 처방 데이터는 저장소에 두지 않습니다.
- 기능: 548처방 DB, 처방/추가약재 분리 파서, 중경 원전 10일분 첩수·소아 체중 연산, A4 세로(1줄 가로 조제지)·가로 2단 조제지 인쇄, 키보드 직통 워크플로우.
- 기억하기: 첫 입력 때 `이 기기에서 기억하기`를 켜 두면 그 기기에서는 다음부터 바로 열립니다. 우측 상단 `잠금` 버튼으로 기억을 지우고 다시 잠글 수 있습니다.
