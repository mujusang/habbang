## 유방별 각론을 더하는 법 (10~20)

총설 제10장에 유방별 파일 이름 규칙이 표로 들어 있습니다. 순서대로 하면 됩니다.

```bash
# 1. 유방 하나를 md 로 쓴다 (예: 계지제 17방)
cp /path/10_계지제.md src/

# 2. docs.txt 에 한 줄 추가 — 파일 맨 아래 주석 처리된 줄을 살리면 된다
#    10_계지제.md | 10 계지제 17방

# 3. 빌드 · 배포
python3 build.py
cd .. && git add -A && git commit -m "10 계지제 반영" && git push
```

각 장은 다섯 단으로 씁니다.
**① 약물 구성과 조합의 원리 → ② 처방 100%의 영역(방증상대) → ③ 복진 확증 지표 → ④ 감별·가감·변방 운용 → ⑤ 치험례.**

주소는 그대로입니다. `src/*.md` 를 고치고 `build.py` 만 다시 돌려도 됩니다.
